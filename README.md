# excel-product-analysis-dashboard
Built interactive Product Dashboard in Excel analyzing 450M Sales &amp; 70M Profit. KPIs, YoY trends &amp; Profit %. Added slicers for Year, Category, Brand, Region, State for filtering. Visuals: Product Sales vs Profit, Category Donut, Monthly Trend, Sub-Category &amp; Brand Profit charts. Tools: Pivot Tables, Pivot Charts, Slicers, Formatting.
